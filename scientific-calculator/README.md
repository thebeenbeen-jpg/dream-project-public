# آلة حاسبة علمية رسومية

آلة حاسبة علمية بواجهة رسومية وراسم دوال، تعمل بالكامل داخل المتصفح بدون خادم.

## المميزات

- عمليات علمية: sin و cos و tan وعكسها، و ln و log و الجذر التربيعي والقوى والمضروب والنسبة المئوية
- وضع الزوايا بالدرجات أو الراديان
- سجل حسابات قابل لإعادة الاستخدام
- راسم دوال f(x) على لوحة رسم مع شبكة ومحاور
- لوحة مفاتيح كاملة واختصارات من الكيبورد

## النشر

موقع ثابت (static site) منشور على Render من هذا المستودع. ملف واحد `index.html` بدون خطوة بناء.
